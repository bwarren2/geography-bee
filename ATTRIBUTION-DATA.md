# Data sources

The hook text in `hooks/` is original writing, not drawn from any of the sources
below. Its export lists are compiled by hand rather than taken from a dataset,
because the comprehensive trade datasets carry licence terms this project cannot
meet — treat them as indicative and worth checking before relying on them.

Everything in `public/data/` is generated by `npm run build:data` and committed to the
repo. The app makes no network calls at build or runtime.

| Source | Used for | License |
| --- | --- | --- |
| [world-atlas](https://github.com/topojson/world-atlas) (Natural Earth) | Country geometry at 110m / 50m / 10m | Public domain |
| [world-countries](https://github.com/mledoze/countries) | ISO codes, names, capitals, borders, area, currencies, languages, flags | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| [country-json](https://github.com/samayo/country-json) | Population, average elevation, coastline, national dish | MIT |
| [NASA Blue Marble](https://visibleearth.nasa.gov/images/57730/the-blue-marble-land-surface-ocean-color-and-sea-ice) | `public/data/terrain.jpg`, the optional satellite base layer | Public domain (NASA) |

The satellite image (8192×4096 equirectangular) is NASA Visible Earth #57730,
"The Blue Marble: Land Surface, Ocean Color and Sea Ice". It is vendored from
a pinned commit of github.com/franky-adl/threejs-earth, whose README sources
that exact file, because visibleearth.nasa.gov is not reachable from every
build environment — `npm run fetch:terrain` re-downloads it from that pinned
commit. NASA imagery is not copyrighted; NASA requests attribution as "NASA
Earth Observatory".

## ODbL note

`world-countries` is published under the Open Database License. It requires
attribution (this file) and share-alike for any *derived database* that gets
publicly distributed. `public/data/countries.json` is such a derived database, so it
stays under ODbL; the application code around it does not.

## Known data caveats

Recorded here because the pipeline works around them, and an upstream fix could
make the workarounds silently wrong:

- **`country-json`'s ISO-numeric bridge table is unreliable.** It omits ~20
  countries (including Russia and Kazakhstan) and gives Montenegro the code
  `382`, which is unassigned — Montenegro is `499`. The pipeline therefore
  treats `world-countries` names as authoritative and accepts a bridge entry
  only when the code names a country actually in our set.
- **`world-countries` flags Vatican City as a UN member.** It is a permanent
  observer, not a member, and Palestine — the other observer — is flagged
  `false`. Taking the flag as-is and adding Palestine happens to land on exactly
  the 195 countries we want, which is why the pipeline asserts that count.
- **Tuvalu is absent from the 50m topology.** It is extracted from 10m into
  `public/data/geo/extra-features.json` and merged as plain GeoJSON at runtime.
- **29 countries are absent from the 110m topology** — all microstates and small
  island nations. They are sub-pixel on a world map anyway, so the world view
  renders them as markers. `inWorldGeometry` flags them.
- **Population figures are ~2018 vintage** and average elevation is missing for
  48 countries. Both are supplementary context, not quiz answers.
